CubeX 是 2021 年 11 月开始跑的。最早只是一起玩的朋友找地方建东西，后来慢慢有了生存、RPG、生电几个模式，也开始自己写插件。

现在它更像一个长期项目：服务器要维护，玩法要更新，插件要跟着 Minecraft 版本走。

<!-- more -->

## 为什么要自己写插件

一开始用的是现成的插件，装一堆，配置改来改去。但有些玩法现成插件做不了，或者做出来总差一点意思。比如：

- 铁砧强化系统，想要自己的成功率和失败惩罚；
- 海上捞漂浮物，想要《木筏求生》那种感觉；
- 修仙系统，想要打坐、境界和武者两条线；
- “水是剧毒的”，想要泡水越久惩罚越重。

这些东西要么没有合适的插件，要么现成的太重。索性自己写。

写插件和写普通 Java 程序不太一样：要熟悉 Bukkit / Paper 的 API，要知道什么是主线程，要处理玩家离线、换世界、死亡、重连这些边界情况。Folia 出来之后又多了一层区域调度器。

## 服务器教会我的事

开服之前以为最难的是写代码，后来发现维护更重要。

- 更新要跟版本。Minecraft 每次大版本更新，Paper API 都可能变，插件要跟着改。
- 数据要能迁移。玩家的等级、装备、进度不能因为一次更新就没了。
- 出问题要能回滚。配置和插件都要留旧版本。
- 玩家反馈比想象中具体。“这个成功率太低了”“这个提示看不清”，都是可以直接改的。

这些经验反过来也影响了写插件的方式：配置尽量外置，消息单独放 `messages.yml`，数据写进 PDC 或数据库，尽量不做“只能跑一次”的硬编码。

## 现在的 CubeX

服务器现在有生存、RPG、生电等几个模式，插件大部分自己维护。主页在这里：

<https://cubexmc.org/>

如果你想玩，可以先看看主页的加入方式。服务器不收费，也没有强制氪金，主要靠大家一起维护。

## 接下来

继续把插件写下去。HammrEnhance、Hooked、SimpleXiuzhen、WaterIsHighlyToxic 都在 GitHub 上，有兴趣可以自己拿去改。

开服这件事大概会继续做下去，毕竟已经五年了。
