旧站是 2024 年用模板搭的：白底、橙色标题，首页放着自己的 Minecraft 皮肤，照片走外链图床，博客区是几张换过文字的卡片。

<!-- more -->

那时候没想太多，能把东西摆上去就行。后来慢慢发现问题：加一篇文章要手改 HTML，外链图片偶尔挂掉，手机上排版也有点挤。拖到今年，终于决定重做。

## 为什么用 Hexo

最直接的原因是写文章方便。现在每篇都是 `source/_posts` 下的一个 Markdown 文件，标题、分类、标签写在文件头，正文正常写就行。构建和部署交给 GitHub Actions，推上去就自动发布，不用在本地折腾。

我还加了一个本地的写作台，`npm run write` 会打开一个简单的编辑器，能新建文章、传图片、看预览。这样不用记 front matter 的格式。

## 搬了什么

- 旧站的照片挑了 15 张，压缩后放到[照片页](/photos/)。原来的外链图床就不用了。
- GitHub 上的项目整理到了[项目页](/projects/)，写清楚每个项目是做什么的。
- Minecraft 相关的内容放到了[游戏页](/games/)，包括 CubeX 和几个插件。

旧站的首页截图留在了这篇文章的封面里。白色背景、橙色 AdLamb，还有那个举着镐子的皮肤——现在看还是挺喜欢的，只是不适合继续往上堆东西了。

旧站的完整文件我留在仓库的 [`old` 分支](https://github.com/AdLambXD/AdLambXD.github.io/tree/old)，想怀旧的话还能翻到。

## 接下来

会写一些开发记录，主要是 Minecraft 插件和 4link。也可能发点照片，但不会为了更新而更新。

如果你是从旧站过来的，欢迎随便看看。评论用的是 Giscus，登录 GitHub 就能留言。
